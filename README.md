# 安心服药（MedicationReminder）

一个面向老人及长期用药者的开源安卓服药提醒应用。第一版完全离线：不注册账号、不连接服务器、不声明网络权限。它只负责记录与提醒，不推荐剂量、不判断药物相互作用，也不提供诊断或治疗建议。

## 功能

- 按计划可靠提醒：每天固定时间、指定星期、每 N 天，可选疗程结束日期。
- 全屏服药提醒、确认已服用、10 分钟后提醒、跳过。
- 同一分钟的多种药合并为一个提醒页，每种药分别确认。
- 服药历史、补充库存与手动更正记录。
- 库存预计不足 7 天时，每天 09:00 发送一次补药通知（时间可在设置中调整）。
- 本地 JSON 备份导出与导入（不含设备标识）。
- 老年友好界面：大字号、高对比、大触控区域。

## 系统要求

- Android 8.0（API 26）及以上。

## 安装

从 releases 页面下载 APK，或本地构建：

```bash
./gradlew.bat assembleDebug
# 安装产物：app/build/outputs/apk/debug/app-debug.apk
```

## 权限说明

应用按需请求以下权限：

- 通知权限（Android 13 及以上）。
- “闹钟和提醒”特殊访问（精确闹钟，Android 12 及以上）。
- 全屏提醒特殊访问（Android 14 及以上）。
- 接收开机完成事件，用于恢复提醒。

应用不声明 `INTERNET` 权限，不包含广告、分析或第三方账号 SDK。

## 提醒可靠性说明

- 普通清除最近任务**不会**取消已安排的系统闹钟。
- 在系统设置中“强制停止”应用后，安卓会取消提醒；应用再次启动时会重新安排并告知用户。
- 精确闹钟权限被拒绝时，提醒会降级为不精确提醒，首页会持续显示“提醒时间可能延迟”。

## 备份与隐私

- 备份导出通过系统文件选择器完成，导出前请知悉文件包含敏感的用药信息，妥善保管。
- 数据仅保存在应用沙箱内，卸载应用即删除本地数据。

## 免责声明

本应用不提供医疗建议。用药计划请遵循医生或药师指导。请勿依据本应用自行调整剂量。
