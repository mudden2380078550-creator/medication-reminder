# 安心服药 · MedicationReminder

一个面向老人及长期用药者的**开源、离线优先**安卓服药提醒应用。

完全离线：不注册账号、不连接服务器、不声明网络权限。它只负责记录与提醒——**不推荐剂量、不判断药物相互作用、不提供诊断或治疗建议**。

- 许可证：GPL-3.0
- 平台：Android 8.0（API 26）及以上
- 技术栈：Kotlin · Jetpack Compose · Room · AlarmManager

## 功能特性

**可靠提醒**

- 支持多种服药计划：每天固定时间、指定星期、每 N 天，可选疗程开始/结束日期
- 同一分钟的多种药合并为一个提醒页，每种药**分别确认**，避免一次误触扣错全部库存
- 全屏服药提醒：锁屏时点亮屏幕展示，权限不允许时自动降级为高优先级通知并明确告知
- 未处理时 10 / 20 / 30 分钟各重提醒一次，40 分钟无操作转为「未确认」，之后仍可更正
- 手机重启、时区变更、时间变更、应用升级后，自动从数据库重建所有待处理提醒
- 普通清除最近任务**不会**取消系统闹钟；「强制停止」后再次打开应用会重建提醒

**库存与记录**

- 记录当前库存、单次用量与用药备注
- 确认「已服用」才扣减库存（整数毫单位存储，杜绝浮点累积误差）
- 补充库存、手动更正均留有流水记录，更正不会覆盖历史
- 库存预计不足 7 天时，每天 09:00 发送一次补药通知（时间可在设置中调整）

**数据与隐私**

- 本地 JSON 备份导出与导入，不包含设备标识
- 数据仅保存在应用沙箱内，卸载即删除
- 无广告、无分析、无崩溃上报、无第三方账号 SDK

**老年友好**

- 大字号（正文 ≥16sp、药名 20sp、关键时间 30sp）、高对比、大触控区域（≥56dp）
- 支持系统字体放大与 TalkBack，核心流程无遮挡

## 界面一览

> 截图将在第一版稳定后补充至 `docs/screenshots/`。

- **今日**：下一次服药时间卡片 + 按紧急程度排序的药箱库存卡片（琥珀色标注低库存）
- **药箱**：药品与计划管理，三步向导添加/编辑药品
- **记录**：服药历史，未确认记录可更正为已服用/已跳过
- **设置**：声音、振动、补药提醒时间、能力状态与本地备份

## 技术栈与架构

| 层 | 说明 |
|---|---|
| UI | Jetpack Compose + Material 3，手动依赖注入（`AppContainer`） |
| 领域 | 纯 Kotlin：日程计算引擎、库存预测器、事件状态机（可确定性测试） |
| 数据 | Room（5 张表）、DataStore（简单设置） |
| 提醒 | `AlarmManager` + `PendingIntent` 广播，精确闹钟优先、降级不精确 |

### 数据模型

- **Medication**：药品名、单位、当前库存、备注
- **MedicationSchedule**：用量、计划规则（Daily / Weekly / EveryNDays）、疗程
- **DoseEvent**：计划时间、状态（待服用 / 稍后提醒 / 已服用 / 已跳过 / 未确认）、重提醒次数
- **StockTransaction**：补充 / 消耗 / 更正流水

数量一律以**千分之一毫单位（Long）**存储，支持半片、毫升小数而不产生浮点误差。

## 开始使用

### 下载安装

从 [Releases](../../releases) 下载 APK，传到手机安装（需允许「安装未知来源应用」）。

### 从源码构建

依赖：JDK 17、Android SDK（compileSdk 37，minSdk 26）。

```bash
./gradlew.bat assembleDebug          # 调试包 → app/build/outputs/apk/debug/
./gradlew.bat testDebugUnitTest      # 单元测试
./gradlew.bat lintDebug              # 静态检查
./gradlew.bat assembleRelease        # 发布包（未签名）
```

## 权限说明

应用按需请求以下能力：

| 权限 | 用途 |
|---|---|
| 通知 | Android 13+ 需要，否则收不到提醒 |
| 闹钟和提醒 | Android 12+ 精确闹钟，拒绝则降级为不精确提醒并提示 |
| 全屏提醒 | Android 14+ 锁屏全屏提醒，拒绝则降级为顶部通知 |
| 开机完成 | 重启后重建提醒 |

应用**不声明 `INTERNET` 权限**。
